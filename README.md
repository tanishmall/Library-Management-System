# Library Management System

![Library Management System](https://github.com/tanishmall/Library-Management-System/raw/main/assets/library-management-system.png)

## Overview

The **Library Management System** is a command-line interface (CLI) program designed to streamline the management of library functions, including book and patron management, checkouts, and returns. Built with Python and MySQL, this system aims to simplify and automate routine library operations.

## Features

- **Book Management**: Add, update, and delete book records.
- **Patron Management**: Register and update patron details.
- **Checkout and Return**: Manage book checkouts and returns.
- **Search Functionality**: Find books and patrons easily.
- **Reporting**: Generate various operational reports.

## Prerequisites

Ensure you have the following installed:

- **Python 3.x** - For running the application.
- **MySQL** - For the database.
- **MySQL Connector for Python** - To connect Python with MySQL.
